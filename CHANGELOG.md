# Change Log

Все заметные изменения в расширении "Extension VS Code" будут задокументированы в этом файле.

Формат основан на [Keep a Changelog](http://keepachangelog.com/), а проект придерживается [Semantic Versioning](http://semver.org/).

---

## [0.0.1] - 2026-06-06

### ✨ Добавлено
- 🎯 Инициальный релиз расширения Extension VS Code
- 📋 6 основных команд для PHP разработки:
  - **Database** (`de_db`) - Шаблон подключения к MySQL БД
  - **Admin** (`de_admin`) - Логика администрирования
  - **Login** (`de_login`) - Функция аутентификации пользователя
  - **Register** (`de_reg`) - Функция регистрации пользователя
  - **Application** (`de_app`) - Основная логика приложения
  - **Request Application** (`de_req_app`) - Обработка запросов приложения
- 🔧 Система автодополнения для быстрого доступа к snippets
- 📝 Полная документация в README.md
- 🏗️ Модульная архитектура для легкого расширения функционала

### 🐛 Исправлено
- ✅ Исправлена структура `template` в JSON файлах - преобразованы из строк в массивы
- ✅ Корректирована команда для `login` модуля (была неправильно установлена)
- ✅ Корректирована команда для `register` модуля (была неправильно установлена)
- ✅ Обновлены скомпилированные файлы расширения

### 🔄 Изменено
- Улучшена структура проекта для лучшей организации кода
- Оптимизирована сборка через esbuild

### 📋 Требования
- VS Code >= 1.120.0
- Node.js >= 18.x
- TypeScript >= 5.9.x
