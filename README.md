# Extension VS Code

Простое расширение для VS Code с командой "Hello World".

## Features

Добавляет команду "Hello World" в командную палитру VS Code.

## Usage

1. Нажмите `Ctrl+Shift+P`
2. Введите "Hello World"
3. Получите приветственное сообщение

## Requirements

VS Code version 1.120.0 или выше.
