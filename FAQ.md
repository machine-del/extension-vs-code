# 🔧 Frequently Asked Questions (FAQ)

Ответы на часто задаваемые вопросы о расширении **Extension VS Code**.

---

## 📦 Установка и настройка

### Q: Как установить расширение?

**A:** Существует несколько способов:

1. **Через маркетплейс VS Code:**
   - Откройте Extensions (`Ctrl+Shift+X`)
   - Поиск "Extension VS Code"
   - Нажмите Install

2. **Локальная установка:**
   ```bash
   git clone https://github.com/machine-del/extension-vs-code.git
   cd extension-vs-code
   pnpm install
   pnpm run compile
   code --install-extension extension-vs-code-0.0.1.vsix
   ```

### Q: Какая версия VS Code требуется?

**A:** Минимум **VS Code 1.120.0** или выше.

### Q: Можно ли установить на macOS/Linux?

**A:** Да! Расширение полностью кроссплатформенное и поддерживает:

- Windows 10/11
- macOS 12+
- Linux (Ubuntu 20.04+)

### Q: Сколько места занимает расширение?

**A:** Примерно 150-200 KB в развернутом виде. Очень легкое!

## 🚀 Использование

### Q: Как использовать snippet?

**A:** Двумя способами:

1. **Автодополнение:**
   - Откройте PHP файл
   - Начните вводить префикс (например, `de_db`)
   - Выберите из списка автодополнения

2. **Командная палитра:**
   - Нажмите `Ctrl+Shift+P`
   - Введите название команды
   - Нажмите Enter

### Q: Почему snippet не вставляется?

**A:** Проверьте:

- [ ] Файл имеет расширение `.php`
- [ ] Расширение активировано (должно быть видно в списке Extensions)
- [ ] Нет активного диалога или других модальных окон
- [ ] Попробуйте перезагрузить VS Code: `Ctrl+Shift+P` → "Reload Window"

### Q: Можно ли отключить автодополнение?

**A:** Да. Добавьте в `settings.json`:

```json
"[php]": {
  "editor.suggest.enabled": false
}
```

### Q: Как редактировать snippet шаблоны?

**A:** Пока встроенного редактора нет, но вы можете:

1. Отредактировать JSON в `src/data/<category>/index.json`
2. Пересобрать: `pnpm run compile`
3. Перезагрузить VS Code

### Q: Можно ли использовать с другими языками кроме PHP?

**A:** На данный момент расширение оптимизировано для PHP. Поддержка других языков планируется в будущих версиях.

## 🐛 Проблемы и их решение

### Q: "No such file or directory" ошибка при установке

**A:** Убедитесь:

- [ ] VS Code установлен в стандартной директории
- [ ] У вас есть права администратора
- [ ] Попробуйте установить .vsix файл вручную:
  ```bash
  code --install-extension path/to/extension-vs-code-0.0.1.vsix
  ```

### Q: Snippet появляется, но вставляется не полностью

**A:** Это может быть из-за:

- Специальных символов в шаблоне
- Проблем с кодировкой файла (должна быть UTF-8)
- Проверьте консоль: `Ctrl+Shift+`J``

### Q: Расширение замедляет работу VS Code

**A:** Это маловероятно, т.к. расширение очень легкое. Проверьте:

- [ ] Отключите другие расширения, которые вы не используете
- [ ] Запустите `pnpm run compile` для пересборки
- [ ] Проверьте требуемую конфигурацию памяти VS Code

### Q: Конфликт с другим расширением

**A:** Если есть конфликт:

1. Отключите подозрительное расширение
2. Перезагрузите VS Code
3. Сообщите об ошибке в GitHub Issues с названием конфликтующего расширения

### Q: Как очистить кэш расширения?

**A:** Иногда помогает:

```bash
# Windows
rmdir %APPDATA%\.vscode\extensions\extension-vs-code* /s

# macOS/Linux
rm -rf ~/.vscode/extensions/extension-vs-code*
```

Затем переустановите расширение.

## 👨‍💻 Разработка

### Q: Как добавить новый snippet?

**A:** 4 простых шага:

1. Создайте JSON конфиг в `src/data/<category>/index.json`:

```json
{
  "command": "extension-vs-code.mycommand",
  "prefix": "de_mycmd",
  "template": ["Ваш код здесь", "Вторая строка"]
}
```

2. Создайте модуль в `src/modules/mycommand.module.ts` (скопируйте из существующего)

3. Зарегистрируйте в `src/middleware/index.ts`:

```typescript
import { MyCommandModule } from "../modules/mycommand.module";
export const modules = [MyCommandModule, ...];
```

4. Добавьте команду в `package.json`:

```json
{
  "command": "extension-vs-code.mycommand",
  "title": "My Command"
}
```

5. Пересоберите: `pnpm run compile`

### Q: Как запустить расширение в режиме разработки?

**A:**

```bash
# В одном терминале
pnpm run watch

# В другом VS Code откройте папку проекта и нажмите F5
# Откроется новое окно VS Code с вашим расширением
```

### Q: Как отладить расширение?

**A:** VS Code имеет встроенный debugger:

1. Откройте файл и установите breakpoint (клик на строке слева)
2. Нажмите F5 для запуска с отладкой
3. Выполняйте команду, и выполнение остановится на breakpoint

### Q: Какие инструменты используются?

**A:**

- **TypeScript** - язык программирования
- **esbuild** - сборщик и минификатор
- **ESLint** - linter для кода
- **VS Code API** - API расширений

### Q: Как запустить тесты?

**A:**

```bash
pnpm run test
```

### Q: Почему мой PR не был принят?

**A:** Возможные причины:

- Код не проходит linting (`pnpm run lint`)
- Конфликты с типами (`pnpm run check-types`)
- Нарушение соглашений о стиле кода
- Отсутствие описания или документации

Если вы не уверены, откройте issue для обсуждения перед PR.

## 🔐 Безопасность и приватность

### Q: Собирает ли расширение данные?

**A:** Нет. Расширение полностью работает локально и не отправляет никакие данные.

### Q: Безопасно ли использовать шаблоны БД с паролями?

**A:** Шаблоны - это только примеры. **Никогда** не используйте реальные пароли. Замените:

```php
// ❌ Плохо
$conn = new mysqli('localhost', 'user', 'realpassword123', 'database');

// ✅ Хорошо
$conn = new mysqli('localhost', 'user', $password, 'database');
// где $password идет из переменных окружения
```

### Q: Можно ли использовать в коммерческих проектах?

**A:** Да! Расширение распространяется под MIT лицензией, которая позволяет коммерческое использование.

## 📊 Производительность

### Q: Влияет ли расширение на скорость работы VS Code?

**A:** Нет. Расширение очень легкое (~200 KB) и не использует много ресурсов. Вы не заметите никакого влияния на производительность.

**A:** Нет. Автодополнение работает мгновенно т.к. данные загружаются один раз при активации.
